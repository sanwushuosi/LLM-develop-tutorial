# 质检小结：clean_text_trafilatura_kept_n40_s0（40 条，good 33 / bad 7）

- **最常见的问题是正文提取没抓到主体，剩下的是站点模板（W03/W05 共 5 次，涉及 4 条）。** 典型样本有：导航菜单加订阅表单提示（honch.co 分类页）；Blogger 侧栏的作者简介和热门文章摘录，帖子本身只有一句（chris4copeland）；UFC 选手页只剩统计栏目名，没有数值（ufc.com）；整条只有主题演示页脚（wigawagaa /footer/）。另有 1 条是报错/加载占位页（W01："No Records Found / Maps failed to load / Loading…"）。
  建议规则：建一个跨页面的行级频次表，按站点统计，删掉在同一站点超过 N% 页面里都出现的行；删完后如果剩下的完整句（中文以句末标点计，英文 ≥8 词且带句末标点）少于 2 句就丢弃。再加一个硬黑名单：命中 `No Records Found|Maps failed to load|Your submission has been received|Oops! Something went wrong` 且完整句不足 3 句的页面直接丢弃。

- **第二类是中文站群/SEO 垃圾（W04 共 2 条）。** 一种是同一个关键词的搜索变体单独成行、穿插在套话之间（“峰哥博客vnp / 峰哥博客免费试用 / 峰哥博客不能用了”）。另一种是“伪原创”：标题字符被打乱，碎片插进句子里（“看点陳妤頡、女标陳圓將”“枪孙中國隊”），而且繁体正文里夹着简体碎片。
  建议规则：(a) 统计 ≤12 字、没有句末标点、且以同一个 ≥3 字前缀开头的短行，出现 ≥3 次就丢弃；(b) 繁体为主的文本里，句中（不在标点边界）出现 ≥3 个由标题字符组成的 2～6 字简体短串时丢弃；也可以用分词器检测标题是否切得出正常词。

- **现有规则判 good、但我认为仍不该进训练的有三类，建议补成 X 规则：**
  X01 城市/地名模板落地页：同一段营销文案只替换城市名，正文段落之间互为同义改写，甚至漏换了地名（tradecorp 的 Nampa 页里出现 "Alameda"；clipa 的 "LEXINGTON, AL"；semaglutide 的 /location/州/市/）。规则：URL 含 `/location/`、`/{state}/{city}/` 这类模式，并且同站点去掉地名后的 MinHash 相似度 > 0.8，就只保留一份。
  X02 软文和关键词嵌入：句子是完整的，但每段都把长尾搜索词硬塞进句子（“国外玩国服游戏加速器推荐考虑稳定性优先”），通篇为单一产品导流（rocio-perez 的“番茄加速器”）。规则：同一个品牌词出现 ≥8 次/千字，并且出现 ≥3 个“海外/国外 + 玩 + 游戏 + 加速器”式的长尾词组时降权或丢弃。
  X03 标题挂博彩品牌的站群：正文是转载的正常新闻，标题却带“-zl尊龙凯时集团”这类后缀（409077.com）。规则：维护博彩品牌词表，标题或标题后缀命中就丢弃，不管正文内容。

- **能写成代码的问题占 bad 样本的大多数：** 7 条 bad 中，表单/报错黑名单、跨页高频行去重、URL 路径（`/footer/`、`/tags/`、`/category/`）规则加起来能拦下 W01/W03/W05/W07 的大部分。代价较高、需要更多信号的是 W04 伪原创（要用标题字符分布）和 X01（要做站内近重复去重）。另外，摘要截断型样本（"...Just as your"、"Click here for the full story"、tag 列表页）按底线口径判 good，但可以按“正文 < 3 句并以截断词或 `...` 结尾”做降权。

- **判定口径说明：** 简短但完整的新闻摘要、公告、档案说明（plunkettcooney、pinchfire、patriotspoint 等）、带少量页脚或推荐阅读的正文、含代码的 man page，一律判 good。规则只按文本本身能看出的问题命中，不靠外部知识判断站点性质：例如“尊龙凯时”是博彩品牌这一点需要背景知识，所以该条判 good，只在 X03 里提出建议。

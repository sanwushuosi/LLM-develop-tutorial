# 质检小结（clean_text_trafilatura_removed_n20_s0，20 条）

结果：bad 15 条，good 5 条。命中次数：W03 x6，W01 x4，W05 x4，G01 x1，W04 x1，W06 x1（012、018 同时命中 W03+W05）。

- **最常见的问题是正文没抓到，只剩页面外壳（W03/W05，10 次命中，涉及 8 条）。** 有的只剩导航菜单，012 的整套菜单还重复了两遍；有的只剩 .gov 横幅（001）或 cookie 横幅（011）；有的是 sitemap 加售票卡片（013）、预订搜索结果的 UI 碎片（002）；还有归档页或列表页只剩标题和被截断的摘要（008、010、018）。
  建议规则：`短行(英文≤4词/中文≤8字)占非空行比例 > 0.8 且 不存在 ≥10 词(或 ≥20 字)的完整句子 → 删除`；
  `以 "..." / "…" 结尾的行(或其下一行是日期)占非空行比例 > 0.5 且 无 >50 词的完整段落 → 删除（摘要列表页）`；
  `连续 ≥10 行的行块在文档内完整出现 ≥2 次 → 删除重复块后再按长度判断`。
- **第二类是人机验证、登录、跳转这类拦截页（W01，4 条：000、003、004、016）。** 文本很短，措辞也固定，最容易用规则拦。
  建议规则：`正文 < 50 词 且 匹配 /request is being verified|verify you are human|checking your browser|Redirect Notice|Forgotten your password|Don.t have an account/i → 删除`；URL 匹配 `google\.[a-z.]+/url\?q=` 的直接丢弃。
- **第三类是只剩模板横幅的极短页（G01/W03：001、005、011）。** 去掉 .gov 横幅、cookie 告知、“nothing here yet / check back later”这类空状态文案后，什么都不剩。
  建议规则：`先删除已知模板句(.gov 横幅、cookie 告知、空状态文案)；删除后正文 < 30 词 → 删除`。
  也可以简化成：`句子数 < 3 且同时含 "cookie" 和 "policy|privacy" → 删除`。
- **少数问题靠 URL 加长度就能拦。** 006 是论坛单楼层回复页，主帖不在（W06），规则：`URL 含 /forums/reply/ 或 /reply/\d+ 且正文 < 100 词 → 删除`。
  017 是站群外链垃圾（W04）：伪原创残句接 escort 推广外链，词间有大量多重空格。规则：`正文 < 80 词 且 含长 slug 外链(imblogs/blogspot 等站群域名) 或 双空格占词间隔比例 > 0.3 → 删除`；外链或 URL 含 escort 等推广词的直接丢弃。

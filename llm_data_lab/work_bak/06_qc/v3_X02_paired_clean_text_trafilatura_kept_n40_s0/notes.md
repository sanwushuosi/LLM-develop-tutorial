# 质检小结（36 条：good 33 / bad 3）

- **整体情况**：这批经 trafilatura 提取并保留下来的样本，底线问题很少，只有 3 条命中：W05×1（013，UFC 运动员页只剩统计字段名和提示语）、W03×1（015，Blogger 本帖只有一句，侧栏作者简介和旧帖摘要占了主体）、W04×1（031，关键词插进句子中间，标题被打乱拼接）。没有出现乱码、HTML/JS 残留、登录/报错页、默认模板页或语言不符。这三类坏样本的共同点是：**原页的正文缺失或被破坏，留下的是页面“外壳”**，比如字段标签、侧栏小部件、SEO 插词。
- **可写成清洗规则的问题**：
  - 字段标签页（013）：`短行(<5词且无句末标点)占比 > 50% 且全文无数字 → 丢弃`。另外按“站点 + 句子哈希”做跨页去重，把同站每页都重复出现的提示句（如 “Sig. Str. Defense is the percentage…”）删掉，删完后剩余太短就整条丢弃。
  - 侧栏摘要（015）：`以 "..." 或 "…" 截断结尾、且与标题没有实词重叠的段落，字数占比 > 50% → 丢弃`。更好的办法是在提取阶段剥离 Blogger/WordPress 的 Popular Posts、About Me 一类侧栏小部件。
  - 插词污染（031）：`同一个 2～6 字片段在 ≥3 个不同句子里出现，且位置在句中而不在句首或标题 → 判为插词`。中文还可以加一条：`繁体正文中夹杂简体片段，或简体正文夹繁体片段`。命中的整条丢弃。
- **按现行规则判 good、但仍值得注意的灰区**（建议在第 6 步补成 X 规则）：
  - SEO 软文和插词：010（番茄加速器软文，句中硬塞“国外玩国服游戏加速器推荐”一类长尾词）、011（“峰哥博客vnp / 峰哥博客不能用了”这类关键词行夹在空泛句子之间）。W04 要求“删掉外壳也找不到成句内容”，门槛太高，这两条都拦不住。
  - 城市模板落地页：029（Christmas Light Installation in LEXINGTON, AL）、035（Shipping Containers in Nampa，同义改写的段落重复，还漏出了另一座城市名 “Alameda”）。
  - 标签/列表页：028，标题和导语粘在一起。W05 对“索引页”有例外，所以判 good。
  - 赌博站镜像新闻：030，标题带“-zl尊龙凯时集团”后缀。认出来需要背景知识，按三问门槛不算命中。
- **建议补充的规则写法**：
  - `X01 关键词插入/SEO 长尾词污染：同一推广短语或站名+搜索后缀（如“xx不能用了/免费试用/vpn”）在正文中以独立行或句中插入的方式出现 ≥3 次，打断正常句子。例外：正文本身在讨论该产品的评测、新闻。` 对应代码规则：标题核心词 + 后缀短语的 n-gram 重复计数，或独立短行与标题高度重合的比例。
  - `X02 模板化落地页：URL 或标题含 /城市/州/ 一类地名槽位，正文按“地名 + 服务”模板生成，段落之间是同义改写或出现与 URL 不一致的地名。例外：真实的本地新闻和机构介绍。` 对应代码规则：同一站点跨页 MinHash 相似度 > 0.8，且差异只在地名 token 上，就整组去重或丢弃。
  - 赌博、灰产镜像站更适合用**域名和品牌词黑名单**在源头过滤（如标题后缀含已知博彩品牌名），不适合让质检员按正文判断。
